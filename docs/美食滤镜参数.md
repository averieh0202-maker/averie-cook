# 美食滤镜 · 默认参数（Averie 定稿 · 曲线版）

调色 RGB 曲线 + UnsharpMask radius=3.7 percent=37 threshold=4

上传默认：**先曲线再锐化**

服务端在 `POST /api/ingest/upload` 与 `POST /api/owner/upload` 写入 MEDIA / D1 / KV / R2 **之前**套用本滤镜。实现见 `api/src/foodFilter.ts`（Workers 纯 JS/TS 像素管线 + `jpeg-js` / `fast-png`；WebP 用 libwebp wasm 解码）。不依赖 Cloudflare 上的原生 ImageMagick。

## RGB 曲线（input → output）

五点控制点，通道独立。LUT 用自然三次样条穿过这些点，再量化到 0–255。

| 通道 | 0 | 64 | 128 | 192 | 255 |
|---|---|---|---|---|---|
| R | 2 | 72 | 147 | 205 | 249 |
| G | 2 | 56 | 130 | 199 | 252 |
| B | 8 | 42 | 128 | 199 | 253 |

## UnsharpMask

Pillow `ImageFilter.UnsharpMask` 语义：

- `radius=3.7`（高斯 σ）
- `percent=37`（amount = 0.37）
- `threshold=4`（仅当 `|原图 − 模糊| ≥ 4` 时锐化）

## 尺寸与编码

- 最长边超过 **1600** 时先缩小（面积平均），再滤镜
- 封面一律输出 **JPEG**，质量 **82**（约 70–85）
- 上传上限仍为 2MB（滤镜前检查）
- 种子烩饭封面已用同一管线滤镜后提交（`jpeg-js` 编码约 124KB；协调员用其它编码器曾压到约 87KB）
